# 对称加密

保密性（confidentiality）的机制基础。这条笔记把 Lecture 1 的安全术语框架和 Lecture 2 的对称密码串起来：从「为什么古代替换密码必死」到「现代分组密码怎么用、会怎么坏」。

## 安全框架：威胁、服务、机制、算法

- 安全永远是**相对的**：相对于想达到的性质，以及假设的攻击者能力。要问「是否合适、强度够不够、成本划不划算」。
- **无条件安全（unconditional）**：无论攻击者算力多大都破不了——只有 one-time pad 做到。**计算安全（computational）**：当前算力下不可行（如暴力破解 AES）。按成本衡量的一类不可全信，攻击者动机难预测。
- **CIA triad**：Confidentiality（防未授权**泄露**）、Integrity（防未授权**修改**，含改/删/插）、Availability（防未授权**阻断**，即 DoS）。
- 关键区分：confidentiality 追求**预防**（泄露后发现也救不回明文）；integrity **无法预防**，只能**检测**（理想情况再恢复）。设计时先问：我是在 prevent、detect 还是 recover？
- Threat（可能危及安全政策的手段）→ countermeasure / vulnerability / attack（威胁的实现）。**Service**（提供什么，如 confidentiality）≠ **mechanism**（怎么提供，如 encryption）。一个机制可支撑多个服务（数字签名同时给 integrity 与 origin authentication），一个服务也可由多种机制实现。
- **Entity authentication**：某时刻验证声称的身份，防 masquerade/replay。**Origin authentication**：验证数据来源，不防 replay 或延迟。**Non-repudiation** of origin / delivery。**Access control**（subject–action–resource）。
- **Kerckhoffs 原则**：算法完全公开，只有 key 保密，不能靠 security through obscurity。Adversary 分 passive（只窃听）与 active（改/删/插、伪造来源）。

## 替换密码与频率分析

Caesar 只有 25 个密钥 → 直接穷举。Simple substitution 的密钥空间是 $26!\approx2^{88}$，暴力不可行（一百万台 3GHz 机器要 4263 年）。但**单表替换不改变字母的相对频率**，频率分析直接破：英文 E 最高（.127），其后 T .091 / A .082 / O .075 / I .070 / N .067；常见双字母 ss/ee/tt/ff/ll/mm/oo；the/and；单字母 a 或 I。还能用 **crib**（猜到的已知词）定位密钥。

多表替换（Vigenère）用多个 Caesar 字母表轮流加密，同一明文字母→不同密文，打乱频率。弱点：**一旦知道关键词长度**，就拆成若干独立 Caesar 分别破解；Kasiski 法用重复串间距的因子估长度。Enigma 状态约 $2^{67}$，致命弱点是一个明文字母**永不加密成自己**，给 crib 提供筛选。

## One-time pad

$C=P\oplus K$，$K$ 与 $P$ 等长、真随机、只用一次。**完美（无条件）安全**：任意密文都能等概率解成任意明文，攻击者得不到任何信息。不可实用：pad 必须与消息等长、安全分发、绝不重用——密钥管理不现实。

## 流密码 vs 分组密码

**流密码**：短 key 喂给确定性 keystream generator 产生 keystream，$C=P\oplus keystream$。**RC4** 分两步：KSA 把 $S$ 初始化成 $0..255$ 的置换并用 key 打乱；PRGA 每步交换并输出一字节。**前 256 字节 keystream 必须丢弃**，否则可能反推 key。优点：快，keystream 函数不必可逆；缺点：**keystream 绝不能重用**，且无完整性——翻转密文一位即翻转明文对应位，已知明文即可恢复 keystream 后篡改（ex02 银行转账例：知道租金收款账户即可把转账账户改成自己的）。

**分组密码**：固定块加密，key 复用。
- **DES**：64-bit 块、56-bit key、16 轮 **Feistel** 结构（每轮只处理一半，轮函数不需可逆）。安全性完全依赖 $f$ 内部，30 年分析未发现后门，最强攻击仍是穷举；差分密码分析需 $2^{47}$ 组选择明文。3DES（两个 56-bit key，E-D-E）、DESX（$C=K_3\oplus DES(K_2,M\oplus K_1)$）。
- **AES**：128-bit 块、key 128/192/256 bit、10~14 轮、**SPN**（每轮处理整块，与 Feistel 不同），四变换 ByteSub / ShiftRow / MixColumn / AddRoundKey，运算在 $GF(2^8)$、不可约多项式 $x^8+x^4+x^3+x+1$ 上。

好的分组密码要满足：**Confusion**（key 变 1 位 → 密文变约 50%）、**Diffusion**（明文变 1 位 → 密文变约 50%）、**Completion**（每个密文位依赖每个 key 位）。穷举：n-bit key 密钥空间 $2^n$，平均试 $2^{n-1}$；现今最小推荐 **128 bit**。

## 工作模式与错误传播

| 模式 | 加密式 | 特点 |
|---|---|---|
| ECB | $C_i=E(K,P_i)$ | 相同明文块→相同密文块；可 cut-and-paste，图像泄露结构。**最不可取** |
| CBC | $C_0=E(K,IV\oplus P_0)$，$C_i=E(K,C_{i-1}\oplus P_i)$ | 链接；相同明文→不同密文；IV 随机但不保密 |
| CTR | $C_i=P_i\oplus E(K,IV+i)$ | 像流密码；可随机读写；IV 重复=灾难 |
| CFB | $C_i=P_i\oplus E(K,C_{i-1})$ | 自同步流式 |

**错误传播**：解密时「密文 1 位错 → 明文多于 1 位错」。CTR 只错 1 位（不传播）；CBC 波及本块与下一块（2 块），**整块丢失**时第 $i$ 块全乱、第 $i+1$ 块仅对应位错，之后重新同步（自同步）；CFB 类似 CBC。CBC 适合随机**读**、不适合随机**写**；CTR 读写皆可。

## 填充

块密码要求整块，末尾需 padding。PKCS7：填充字节值 = 填充长度（填 1 字节 0x01；2 字节 0x02 0x02 …）。**Padding oracle**：实现若返回可区分的「填充错误」，攻击者每字节最多 256 次尝试即可逐字节解密。

## 实践判断

key > 128 bit；算法公开（Kerckhoffs）；开放竞赛产生的标准可信，专有算法要警惕（Mifare Classic 的 Crypto1 被逆向、TI DST 的 40-bit key 数小时破解）；模式优先 CBC（ECB 不行）。
