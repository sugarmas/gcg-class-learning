# 数据可视化陷阱

CS5481 第 4 讲。讲图表怎么选、怎么做，重点是**别踩的坑**。"Traps"一节最耐用——它讲的不是某个软件，而是任何图都适用的判断标准。

## 目的：弥补人脑与数据之间的鸿沟

人脑无法直接处理计算机里的原始数据，却**擅长视觉认知**。可视化 = 对抽象数据的视觉呈现，用来**强化认知**（reinforce human cognition），目标是让信息 easy to comprehend / interpret / retain。两种动机：

- **Exploratory（探索）**：帮自己理解数据、找 insight，仅限内部团队
- **Explanatory（解释）**：传达分析结果，用于 data storytelling / 汇报

它是**科学与艺术的结合**：科学是"选对呈现方式、用对软件"的技能；艺术是要**讲一个故事**。两条原则："Everything should be made as simple as possible, but no simpler." / "Ink is cheap. Electrons are even cheaper."

## 选图之前先问目的

作者归纳的 **6 种做图理由**：① 比较 compare ② 看分布 distribution ③ 部分占整体 parts of whole ④ 随时间趋势 trend over time ⑤ 找偏差 deviations ⑥ 理解关系 relationship。同时要问：**受众的 key takeaway 是什么、他们需要知道什么、他们有什么问题**。

## 常规图表的适用场景

- **Bar / Column**：比较相关数据集或整体的一部分；column（竖条）可比并展示随时间的变化
- **Pie**：把实体拆成子部分的比例，每个扇区是静态值，总和 100%
- **Stacked bar**：整体拆成部分，**常比 pie 更好**，可容纳多个离散维度
- **Histogram**：一维，"看数据的第一种重要方式"，通过对连续分布分箱展示形状
- **Venn**：展示离散组的重叠，有时是**唯一**能表达重叠集的方式，但没有 "popout"，不直观
- **Scatter**：两个连续维度上观测值的关系，可分组、加趋势线；**数据太多时就没信息了**
- **Line**：把离散测度画成连续，可比较多个离散组
- **Dynamite plot**：适合多分组因子，分组语义自然，但**掩盖数据**
- **Heat map**：有自然语义时很好；**颜色映射容易出问题**（grayscale 通常更稳）；可能不直观
- **Bubble**：很直观，但**面积/尺寸不是完美定量的**
- 其他：gauge（沿弧线指示指标值）、3D plot（提供 depth/breadth/height 的知觉）

## 技巧与取舍

三个"do more with less"的技巧：**Multiple plots**（简单易读的子图，但可能 overwhelming）、**Hybrid plots**（如 histograms 的散点图、histograms 的 venn 图）、**Multiple axes**（把两件不同的事画在一张图上）。

两个根本取舍：

- **Informativeness vs. readability**：信息太少会隐藏数据，太多又会淹没读者；解法之一是 hierarchical organization
- **Data-centric vs. viewer-centric**：读者习惯了某些图型，但**新颖的图可能更忠于数据**

## ⚠️ Visualization Traps（重点）

1. **Wrong plot types**：注意 x 轴一般是自变量（independent），y 轴是因变量（dependent）。
2. **不同颜色用法带来不同印象**：不同 scheme 会凸显某些特征、淡化另一些；而且**并非所有 palette 都兼容黑白打印**。
3. **Exaggerated plot scale（夸大坐标尺度）**：把 y 轴截断/放大，能让一条平缓的曲线看起来"剧烈波动"、月末"令人担忧地下跌"——一旦看 y 轴的真实范围，就没那么吓人了。对策之一是**用 log-scale 展示完整信息**。
4. **常见错误清单**：① 图没有标题 ② 未给数据来源 ③ 没有图例 ④ 坐标轴尺度被中断 ⑤ 尺度没标 ⑥ 符号大小不一致或间距不等 ⑦ 用 3D 物体去比面积/体积 ⑧ 尺度不从零开始 ⑨ 轴上数字间距不等 ⑩ 为了得到想要的结果而故意选尺度（**误导**）。

记忆锚点：⑧⑨⑩ 都是"动了坐标轴"——看图时**先看坐标轴从哪开始、间距是否均匀、有没有被截断**，绝大多数误导都藏在这里。

## Dashboard 软件

- **Spreadsheets**：Excel（多种图表类型、会推荐可视化）；Google Sheets（也推荐图型，协作更好）
- **Jupyter + Python**：Matplotlib（最通用，2D/3D）、Bokeh（交互、大流数据）、Plotly Dash（纯 Python 建交互 web app，不用会 HTML/JS）
- **R-Studio / R-Shiny**：R-Shiny 可建交互 web app 与 dashboard
- **IBM Cognos Analytics**：端到端，擅长 geospatial 与预测
- **Tableau**：drag & drop 做 dashboard/worksheet，可发布为 stories，可导入 R/Python 脚本
- **Microsoft Power BI**：云端 BI，快且高效，drag & drop，可安全协作分享
