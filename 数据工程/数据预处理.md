# 数据预处理

CS5481 第 3 讲。真实数据是脏的（dirty data），预处理是"喂给挖掘算法之前"的统称，核心逻辑是 **GIGO**：没有高质量数据就没有高质量结果。六大任务：cleaning / integration / transformation / reduction / discretization。

## 脏数据的三种表现

- **Incomplete**：缺属性值、缺关键属性，或只有聚合数据。例 `Occupation=" "`。
- **Noisy**：含噪声、错误或离群点。例 `Salary="-10"`。
- **Inconsistent**：编码/名称冲突。例 `Age="42"` 却 `Birthday="03/07/2010"`；评分制从 `1,2,3` 改成 `A,B,C`；重复记录不一致。
- 还有 **intentional**（伪装缺失），如把所有人的生日都填成 1 月 1 日。

真实数据常见：用 0/null 代缺失、拼写不一（usa/USA）、无意义符号、重复行、日期格式不一（`10/9/15` vs `9/10/15`）、单位未标。

## Data cleaning

目标：填缺失、平滑噪声、纠正不一致。

**缺失值**（来源：设备故障、冲突被删、录入误解、未记历史）的四种填法：① 忽略元组（常用于 class label 缺失）；② 手工填写（不可行）；③ 自动——全局常量 / 属性**全局均值** / **同类样本均值**（更聪明）/ **最可能值**（回归、贝叶斯、决策树推断）。

**噪声** = 被测量变量中的随机误差。处理方法：

- **Binning**：排序分箱后按箱均值/中位数/边界平滑。**Equal-width** 把 `[A,B]` 均分 N 段，宽 $W=(B-A)/N$：最直接，但**离群点会主导**、skewed 数据差；**Equal-depth** 每箱样本数相近：scaling 好，但类别属性难处理。例（价格 4,8,9,15,21,21,24,25,26,28,29,34 分三箱）：bin means → 9×4 / 23×4 / 29×4；bin boundaries → 4,4,4,15 / 21,21,25,25 / 26,26,26,34。
- **Clustering**：检测并移除离群点（k-means 常优于 binning）
- **Semi-automated**：机器检测 + 人工核查
- **Regression**：拟合回归函数平滑

**不一致**：借助 **metadata**（domain/range/dependency/distribution）、field overloading、uniqueness/consecutive/null 规则校正；半自动工具如 **data scrubbing**（用邮编、拼写等知识纠错）、**data auditing**（用相关/聚类找规则违例者）。

## Data integration

把多源合成 coherent store。难点：**schema integration** 与 **entity identification problem**（识别同一个现实实体）；**值冲突**（不同表示/尺度，Metric vs British、货币）。集成易产生**冗余**（同属性异名，或某属性可由他表派生如 annual revenue），用相关分析检测：

$$r_{A,B}=\frac{\sum(A-\bar A)(B-\bar B)}{(n-1)\,\sigma_A\sigma_B}$$

## Data transformation

- **Smoothing** 去噪；**Aggregation** 汇总（构建 **data cube**，支持 drill-down / slicing-dicing / pivot）；**Generalization** 生成 concept hierarchy
- **Normalization** 缩放到指定小区间，三法：**min-max** $v'=\frac{v-\min_A}{\max_A-\min_A}(\text{new\_max}-\text{new\_min})+\text{new\_min}$；**z-score**（即 standardization，零均值单位方差）$v'=\frac{v-\bar A}{\sigma_A}$；**decimal scaling** $v'=v/10^j$，$j$ 取使 $\max(|v'|)<1$ 的最小整数
- **Attribute construction**：由已有属性造新属性

**Regex** 是得力工具：指定搜索模式的字符序列，用于匹配、查找替换、抽取子串。

## Data reduction

仓库动辄 TB 级，目标是 volume 小得多、但分析结果**几乎相同**的 reduced representation。策略：**data cube aggregation**；**dimensionality reduction**（feature selection，副作用是模式更易理解）；**data compression**（字符串 lossless / 音视频 lossy / 时间序列）；**numerosity reduction**——parametric（如 log-linear，只存参数）或 non-parametric（histogram / clustering / sampling），聚类质量看 **diameter** 或 **centroid distance**，**stratified sampling** 保各类比例；以及 discretization。

## Data discretization

属性三型：**nominal**（无序集）、**ordinal**（有序集）、**continuous**（实数）。把连续属性值域切成区间，因为有些分类算法只吃 categorical，也能减小数据量。**Concept hierarchy** 把低层概念（age 数值）换成高层（young / middle-aged / senior）。

数值数据方法：① 递归分解（binning / histogram / clustering）；② **entropy-based**：阈值 T 二分 S，信息增益 $I(S,T)=\frac{|S_1|}{|S|}E(S_1)+\frac{|S_2|}{|S|}E(S_2)$，$E(S_1)=-\sum_{i=1}^{m}p_i\log_2 p_i$；取使增益最大的 T，递归到 $E(S)-I(S,T)\le\varepsilon$ 停止；③ **natural partitioning（3-4-5 rule）**：最高有效位覆盖 3/6/7/9 → 切 3 段，2/4/8 → 4 段，1/5/10 → 5 段。
