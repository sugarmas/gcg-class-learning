# 视频压缩基础

Data compression 的目的是用更少的 bit 表示数据。压缩之所以可能，是因为数据里有**可被利用的模式 / 冗余**，例如把 `AAAAAA` 表示成 `6A`——解码端靠这条"描述"恢复原序列。

## bit、byte 与 bit depth

1 bit = 0 或 1，1 byte = 8 bit。bit depth 表示一个值用多少 bit：1 bit → 2 种取值，8 bit → 256 种（0–255）。RGB 一个像素每通道 8 bit。

**原始大小**：

$$\text{raw size}=\text{pixels/frame}\times\text{bytes/pixel}\times\text{frames}$$

例：640×480 RGB、30 fps、10 s → $307{,}200\times3\times300=276{,}480{,}000$ B $=276.48$ MB。

**压缩比**：$\text{ratio}=\text{original}/\text{compressed}$，如 100 MB→20 MB 是 5:1，省空间 $(100-20)/100=80\%$。**lossless** 可精确还原，**lossy** 允许信息损失换更高压缩比。

## 用冗余换压缩

- **RLE 游程编码**：`AAAAABBCCCCCAA` → `(5,A)(2,B)(5,C)(2,A)`。重复少时反而变大。
- **字典编码**：重复字符串用共享短码替代。
- **预测 + 残差**：用前值预测当前值，只存残差。值 102,101,103，预测 100,102,101 → 残差 +2,−1,+2；存首值 100 加残差即可重建（$102=100+2$）。

统计冗余用**熵编码**：给高频符号短码字。`AAAABBCD` 固定长编码 2 bit×8=16 bit；变长编码 A=0, B=10, C=110, D=111 → $4\cdot1+2\cdot2+1\cdot3+1\cdot3=14$ bit。Huffman 编码反复合并频率最低的两组，例如 `SEMESTER`（E×3, S×2, M/T/R×1）只要 18 bit，而固定长 3 bit×8=24 bit。

**熵** $H=-\sum p\log_2 p$（平均不确定度，bit/symbol）是平均码长的下界（Shannon）。四个等概率符号 → 2 bit/symbol；`AAAABBCD`（概率 1/2,1/4,1/8,1/8）→ $H=1.75$ bit/symbol。实践用 Huffman / Arithmetic；短块（5–10 符号）Huffman 好，长块（>10）算术编码更好。

## 变换、量化与失真

**变换编码**：换一种表示让数据更好压。例 100,102 → 均值 101、细节 $(-1,+1)$，可无损还原。JPEG/视频用 **DCT**，把能量集中到少数低频系数（decorrelate / energy packing），高频可粗量化——利用了人眼对高频不敏感（perceptual redundancy）。

**量化**：把邻近值归到同一重建值，是有损的。例 index=round(value/10)，重建=index×10：101→100（误差 −1）、104→100（−4）、109→110（+1）、112→110（−2）——**101 与 104 的差异被抹掉了**。

**失真度量**：

$$\mathrm{MSE}=\frac1N\sum(x_i-y_i)^2,\qquad \mathrm{PSNR}=10\log_{10}\frac{L^2}{\mathrm{MSE}}\ \text{dB}$$

8-bit 时 $L=255$。上面误差 $1^2,4^2,1^2,2^2$：$\mathrm{MSE}=22/4=5.5$，$\mathrm{PSNR}=10\log(255^2/5.5)\approx40.73$ dB。MSE 越小 / PSNR 越高通常越好，但不完全等于主观画质。

**码率与质量**：$\text{size(MB)}=\text{rate(Mbit/s)}\times\text{seconds}/8$。8 Mbit/s×60 s = 60 MB，4 Mbit/s→30 MB。量化越强 → bit 越少但失真越大。压缩目标：在最大允许延迟与复杂度约束下，取得 **rate–distortion 最优权衡**。

## 冗余的四个来源与帧类型

- **空间冗余** → intra prediction（帧内预测，参考本帧已编码块）。
- **时间冗余** → inter prediction / motion compensated prediction（分块做 block matching 找 motion vector，编码 MV + 残差）。
- **统计冗余** → entropy coding。
- **感知冗余** → 频域（DCT）粗量化高频。

帧类型：**I 帧**（仅帧内，支持随机访问、抗错误传播、适合大运动）；**P 帧**（前向预测）；**B 帧**（双向预测，需重排序，性能更好但有延迟）。

## 混合编码器与标准

Hybrid encoder = 变换 + 量化 + 熵编码（+ 环内滤波 in-loop filter，如 deblocking 低通边界，消除块效应）。标准约**每十年提升 2× 压缩**，最新为 VVC/AVS3，且标准**只规定 decoder**。端到端学到的图像压缩用 VAE + hyperprior，感知质量好。
