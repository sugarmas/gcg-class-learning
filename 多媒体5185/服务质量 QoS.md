# 服务质量 QoS

QoS（Quality of Service）是**网络层面的质量**（数据发得多快、多久到、丢不丢、延迟稳不稳）；QoE（Quality of Experience）是**用户感受到的体验**（加载快慢、卡不卡、清不清楚）。QoE 受 QoS 影响但不等于 QoS——网速快不代表视频流畅，高延迟或丢包照样卡。

## 四个 QoS 度量

| 度量 | 含义 | 用户可见效果 |
|---|---|---|
| Throughput 吞吐 | 每秒送达的数据量 | 加载慢 / 画质被压低 |
| One-way delay 单向延迟 | 发送到接收的时间 | 实时通话感觉迟钝 |
| Delay variation（Jitter 抖动） | 各包延迟随时间变化 | 播放忽快忽慢 / 卡顿 |
| Packet loss 丢包 | 包没到达 | 画面缺口 / 损坏 |

## 端到端延迟的构成

延迟在链路上逐段累加。示例：

$$\text{End-to-End Delay}=20+15+35+40+10=120\text{ ms}$$

对应顺序为 capture/packetize → encode → network → playout buffer → decode/render。（playout buffer 那一环占最大头 40 ms。）

## Jitter 与 playout buffer

网络延迟不均匀：例包 1–5 的延迟分别为 40, 45, 65, 40, 50 ms，**包 4 甚至早于包 3 到达**（乱序）。Jitter 就是这些延迟的波动。

**Playout buffer（播放缓冲）**：播放器先攒一小段数据再播，把到达时间的抖动"抹平"。它把"发送时刻"错开成"播放时刻"：deadline = 发送时刻 + 选定的播放延迟。

- 发送时刻 0,20,40,60,80，到达 40,65,105,100,130 ms。
- 播放延迟取 **50 ms**（deadline 50,70,90,110,130）：包 3 的 deadline 是 90，但它 105 才到 → **迟到丢帧**。
- 播放延迟取 **70 ms**（deadline 70,90,110,130,150）：全部准时。
- **代价**：缓冲越大越不容易卡，但延迟越大（实时通话受不了）。

## 拥塞时的流量管理

网络拥堵时，要决定"谁被延后、谁被丢弃、谁先走"：

- **Policing（监管）**：检查流量是否超过约定额度，超出的丢弃或降优先级。
- **Shaping（整形）**：把包先存起来、晚点再均匀发出，流量更平滑，但延迟增加。
- **Scheduling（调度）**：决定发送顺序，重要或对延迟敏感的流量先走。

## 流式与自适应

**自适应流（adaptive streaming）**：按当前网速切换码率。若网速 3 Mbit/s：2 Mbit/s 的流下载快于播放，缓冲持续增长，播放流畅；5 Mbit/s 的流下载慢于播放，缓冲被抽干，视频变卡。**网速变差时主动降码率可避免卡顿。**

不同应用权衡不同：VoD 求流畅（多缓冲）、直播求贴近实时（低延迟）、实时通话求快速响应（只缓冲一点）、文件传输求数据正确（丢包重传）。

## 传输错误与恢复

数据被切成 packet 逐个传，噪声可能翻转某些 bit。用**校验位**检测：

- **奇偶校验（parity）**：追加 1 bit，使 1 的个数满足约定。数据 `01101110` 有 5 个 1：偶校验补 1（共 6 个，偶），奇校验补 0（共 5 个，奇）。
- 一个 parity bit 只能检出**奇数个** bit 翻转；翻转偶数个会**漏检**；而且它只能"发现错误"，不能定位是哪个 bit。
- **二维奇偶校验**：数据排成块，每行每列各加偶校验。**单个** bit 错时，出错的行与列相交处就是错误位置（可纠正）；两个 bit 错能检出但定位可能含糊；而**矩形的四个角一起翻**时，每行每列仍是偶数个 1 → **完全漏检**。

并行手段：丢包恢复（重传 / FEC）、码率自适应（bitrate adaptation）。

## 网络与协议

设备 → 接入网（Wi-Fi / Ethernet / 5G）→ Internet → 目的地。协议决定数据怎么送、校验、排序、重传：

| 协议 | 作用 |
|---|---|
| TCP | 可靠、有序的字节流，带拥塞控制 |
| UDP | 数据报，无内建重传/排序（有 checksum） |
| QUIC / HTTP/3 | 在 UDP 之上的可靠流，HTTP/3 架于 QUIC 上 |
| HLS / RTP / RTSP | 分片交付 / 媒体时序 / 会话控制 |
