# 采样与混叠

数字媒体的第一步：**sampling 决定"何时/何处测量"，quantization 决定"每次测量用多少级表示"**。采样的时间/空间间隔就是采样周期 $T_s=1/f_s$；量化由 bit depth $b$ 给出 $2^b$ 个电平。两者共同决定源数据率（raw data rate）。

## 采样定理

若采样频率 $f_s$ **大于信号最高频率分量 $f_h$ 的两倍**，就能从样本无信息损失地重建信号：

$$f_s > 2f_h$$

- 采样周期 $T_s=1/f_s$，例如 $f_s=8$ Hz → 每 $0.125$ s 采一个点。
- **Nyquist frequency** $=f_s/2$，是可以被正确表示的最高频率（超过它就会混叠）。
- **Nyquist rate**（最小无损失采样率）$=2f_h$。

> 注意课件措辞把"Nyquist frequency = $f_s/2$"与"最小采样频率"混着讲；标准分工是：$f_s/2$ 是能表示的最高频率，$2f_h$ 是最小采样率。做题时按"必须 $f_s>2f_h$"判。

## Aliasing 是怎么产生的

采样太慢时，高频信号会伪装成低频信号。例：$f_s=10$ Hz 下，3 Hz 与 7 Hz 的余弦产生的样本完全相同：

$$\text{alias}(f)=|f-k f_s|,\qquad 7\text{ Hz 在 }f_s=10\text{ 下折叠为 }|7-10|=3\text{ Hz}$$

若假定信号频率都在 $f_s/2=5$ Hz 以下，重建就会得到 3 Hz——**样本本身无法分辨原始到底是哪个**。这就是 aliasing（混叠）。

## 抗混叠滤波必须在采样前做

一旦采样完成，高频已经"折叠"进低频频带，与真正的低频分量**不可区分**，事后无法用滤波救回来。所以顺序必须是：

1. **先** 低通滤波，把 $f_c$ 以上的频率滤掉（$f_c\le f_s/2$）；
2. **再** 以 $f_s$ 采样，此时信号带宽已小于 $f_s/2$，不会混叠。

理想低通滤波器 $Y(f)=X(f)H(f)$：$|f|<f_c$ 增益 1（原样保留），$|f|\ge f_c$ 增益 0（完全移除）。例：3 kHz 截止的理想 LPF，1 kHz 分量（幅度 1.0 × 增益 1）保留，5 kHz 分量（幅度 0.4 × 增益 0）被剔除。

**降采样必须先滤波**：为了降数据率而降低采样率时，先滤掉即将超出新 Nyquist 的高频，否则那些高频会折叠成假的低频。

## 原始数据率

**音频**：16-bit PCM $\text{bitrate}=\text{sample rate}\times 16$ bits/sample。保留到 6 kHz 需采样 16 kHz → $16000\times16=256$ kbit/s；只保留到 3 kHz，先滤波再采 8 kHz → $128$ kbit/s。多通道再乘通道数：

$$\text{PCM bitrate}=\text{sample rate}\times\text{bits/sample}\times\text{channels}$$

CD 立体声：$44100\times16\times2=1{,}411{,}200$ bit/s $=176{,}400$ B/s；4 分钟 $=176{,}400\times240=42{,}336{,}000$ B ≈ 42.336 MB ≈ 40.38 MiB。

**视频**：每帧像素 × 每像素字节 × 帧率。1920×1080、24-bit RGB、25 fps：单帧 $1920\times1080\times3=6{,}220{,}800$ B，bitrate $=6{,}220{,}800\times25\times8=1.24416$ Gbit/s；90 分钟 $=6{,}220{,}800\times25\times5400=839.808$ GB。

**采样维度**：图像在 $x,y$ 上空间采样（分辨率 = 空间样本数）；视频还采时间（帧率 = 每秒时间样本数）。帧率太低，运动会显得跳或错误。

## 常见采样率

| 场景 | 采样率 | Nyquist |
|---|---|---|
| 窄带电话 | 8 kHz | 4 kHz |
| Audio CD | 44.1 kHz | 22.05 kHz |
| 48 kHz 音频 | 48 kHz | 24 kHz |
