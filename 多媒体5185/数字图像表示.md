# 数字图像表示

Digital image 的本质：把连续的二维光强场，先在空间上 **sampling**（采样），再在强度上 **quantization**（量化），得到一个像素网格。每个 pixel（picture element）是数字图像的最小单位。

## 像素、分辨率、色深

- 分辨率 resolution = width × height，即像素个数，例：HDTV = 1920 × 1080。
- 二值图像 binary image：1 bit/pixel，取值 0/1，常用于前景/背景。
- 8-bit 灰度图：每像素 8 bit，取值 0–255，0 = 黑，255 = 最亮。
- bit depth b → 电平数 $2^b$：1 bit→2 级，4 bit→16 级，8 bit→256 级。**每加 1 bit，电平数翻倍，台阶更不易察觉。**

## bit-depth 转换为什么丢信息

低 bit 量化会把多个原始值合并进同一码字，这个过程不可逆。例：3-bit 均匀量化，$x\in[0,1]$：

$$k=\operatorname{round}\big((2^3-1)x\big)=\operatorname{round}(7\times 0.63)=\operatorname{round}(4.41)=4$$

码字 4 编成二进制 `100`；反量化 $\hat x=k/7=4/7\approx 0.571$，误差 $\hat x-x\approx -0.059$。

Bit-depth expansion（BDE）想把 3-bit 内容升到 8-bit 显示，两种固定做法：
- 补零 zero padding：`101` → `10100000` = 160（左移 5 位）；
- 查表 table mapping：$k\mapsto\operatorname{round}(k/7\times 255)$，如 1→36、5→182、7→255。

两者结果不同（码字 5：补零得 160，查表得 182），但**都只是估计丢失的低位变化，不是精确恢复**——被量化合并掉的色调回不来。学习式 BDE（如 BitNet）用空间上下文与跨通道信息猜更合理的中间值，能减轻 banding，但仍只是 plausible estimate。

## Gamma correction

显示器发光量与驱动电压不成正比：$\text{light}\propto R^\gamma$，CRT 的 $\gamma\approx 2.2$。要让存储值 $R$ 对应想要的亮度，先编码 $R'=R^{1/\gamma}$，显示时 $(R')^\gamma=R$。这就是补偿显示非线性。

## 直方图与点运算

Histogram $p(g)$ 统计灰度 $g$ 的出现次数：集中在左 → 偏暗，集中在右 → 偏亮；分布窄 → 低对比度，宽 → 高对比度。点运算（逐像素，不依赖邻域）：

- 亮度：$p'=p+\text{brightness}$（直方图水平平移）；
- 对比度：$p'=c\,(p-g_{mean})+g_{mean}$，$c>1$ 拉宽、$c<1$ 压窄，最后 clip 到 [0,255]；
- 反色：$p'=255-p$；阈值化：$p<T$ 取 0、$p\ge T$ 取 255 → 二值图。

## Dithering

设备只有少数物理强度级（黑白打印机只有 2 级）。Dithering 用**空间点阵密度**近似更多灰度级：2×2 点阵能给出 5 种可用强度图案（对应区间 0–50、51–101、…、204–255）。代价是**用空间分辨率换强度分辨率**——一个像素变成一块局部图案。

## PPI 与 DPI（常考易混）

- PPI（Pixel Per Inch）：图像像素密度（显示/输入图像的分辨率密度）。
- DPI（Dot Per Inch）：打印机墨点密度。

二者单位像但**测的不是同一件事**；打印时通过 dithering 把图像像素转成墨点，二者才发生联系。

## 插值

在非整数坐标 $(x,y)$ 估计强度。一个像素单元内 A=I(0,0), B=I(1,0), C=I(0,1), D=I(1,1)：

- 最近邻：$\mathrm{NN}(x,y)=I(\operatorname{round}(x),\operatorname{round}(y))$，快但有块状；
- 双线性：$\mathrm{BL}=(1-x)(1-y)A+x(1-y)B+(1-x)yC+xyD$，平滑但边缘软；
- 双三次：16 个样本的 cubic kernel，更锐利但可能 ringing。

例：A=10, B=20, C=30, D=40，在 $(0.25,0.60)$：

$$\mathrm{BL}=0.30\cdot10+0.10\cdot20+0.45\cdot30+0.15\cdot40=24.5,\qquad \mathrm{NN}=I(0,1)=30$$

插值只用固定核和已有样本；Neural SR（如 SRCNN 从 bicubic 上采样图出发）用训练数据学低分辨率证据与高分辨率细节的关系，估计缺失的高频内容。

## 色彩空间 RGB / YUV / YIQ

- RGB：加色（additive）混合，直接对应显示。24-bit = 8 bit × 3 通道 → $256^3=16{,}777{,}216$ 种颜色；1920×1080 未压缩 RGB = 1920·1080·3 = 6,220,800 B ≈ 5.93 MiB。再加 alpha → 32-bit。
- YUV（PAL）：$Y=0.299R+0.587G+0.114B$，$U=B-Y$，$V=R-Y$。
- YIQ（NTSC）：$Y$ 同上，$I,Q$ 是旋转过的色度轴：

$$I=0.877(R-Y)\cos33^\circ-0.492(B-Y)\sin33^\circ,\quad Q=0.877(R-Y)\sin33^\circ+0.492(B-Y)\cos33^\circ$$

反变换：$R=Y+V$，$B=Y+U$，$G=(Y-0.299R-0.114B)/0.587$。

**为什么要 YUV/YIQ**：人眼对亮度（luminance）远比色度（chrominance）敏感。把亮度单独拆成 Y，就能给 Y 多分配带宽、对色度做子采样（4:2:2 / 4:2:0），在不明显损观感的前提下省数据。RGB 三通道是平等的色原通道，做不到。

## 质量度量

- $\mathrm{MSE}=\frac1N\sum(x_i-y_i)^2$；$\mathrm{PSNR}=10\log_{10}(L^2/\mathrm{MSE})$ dB，8-bit 时 $L=255$。例：参考 [[10,20],[30,40]]、重建 [[12,18],[33,37]]，MSE=(4+4+9+9)/4=6.5，PSNR≈40.00 dB。
- SSIM 比较局部亮度/对比度/结构（$l\cdot c\cdot s$），$C_1=(0.01L)^2$、$C_2=(0.03L)^2$，完全相同为 1。像素误差（PSNR）不完全代表主观观感。
